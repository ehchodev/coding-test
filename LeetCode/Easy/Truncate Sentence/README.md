# 1816. Truncate Sentence

**A sentence is a list of words that are separated by a single space with no leading or trailing spaces.**  
문장은 맨 앞이나 맨 뒤에 공백이 있지 않은 단 하나의 공백으로 구분된 단어들의 목록이다.

**Each of the words consists of only uppercase and lowercase English letters (no punctuation).**  
각각의 단어들은 (문장부호가 아닌) 오직 대문자와 소문자의 영문자로만 구성된다.

- **For example, `"Hello World"`, `"HELLO"`, and `"hello world hello world"` are all sentences.**  
예를 들어, `"Hello World"`, `"HELLO"`, 그리고 `"hello world hello world"`는 모두 문장이다.

**You are given a sentence `s`​​​​​​ and an integer `k`​​​​​​.**  
문장 `s`와 정수 `k`가 주어진다.

**You want to truncate `s`​​​​​​ such that it contains only the first `k`​​​​​​ words.**  
당신은 `s`를 처음 `k`개의 단어까지만 포함되도록 자르길 원한다.

**Return `s​​​​​​` after truncating it.**  
`s`를 자른 후의 결과를 반환하라.
